詳細説明 (4000文字以内)
----------------------------------------------------------------
「今日、結局何時間働いたんだろう？」

WorkLog は、その疑問にだけ答えるアプリです。

出勤したら「出勤」を押す。
休憩したら「休憩する」を押す。
帰るときに「退勤」を押す。

それだけで、今日の実働時間と今月の合計が残ります。
説明書は要りません。初回起動でもチュートリアルはなく、
いきなりホーム画面から出勤できます。


■ かんたんに記録する

・ホーム画面の大きなボタンを押すだけ
・今日 / 今週 / 今月の勤務時間がひと目でわかる
・休憩は1日に何回でも記録できます
・ホーム画面ウィジェットから1タップで出勤・退勤


■ 記録が消えない

WorkLog は常駐タイマーを使いません。
出勤時刻と休憩時刻だけを保存し、経過時間は画面を開くたびに計算します。

そのため、

・バッテリーをほとんど消費しません
・アプリを強制終了しても勤務中の状態が消えません
・端末を再起動しても記録は残ります

という作りになっています。


■ 夜勤・日跨ぎ勤務に対応

9月20日 22:00 出勤 → 9月21日 06:00 退勤 は、
8時間勤務として正しく計算します。
勤務実績は「出勤した日」に計上されるので、
月末の夜勤が翌月に混ざることもありません。


■ 打刻を忘れても直せます

・履歴から日付・出勤・退勤・休憩をあとから修正できます
・打刻し忘れた日の勤務をあとから手入力できます
・退勤 < 出勤 のときは翌日退勤として自動で解釈します
・入力の矛盾はその場で指摘します


■ CSVで書き出せます

日付・出勤・退勤・休憩・実働の CSV を端末内で作成し、
Android の共有シートからファイル・Gmail・Google ドライブなど、
お好きなアプリへ渡せます。
Excel で文字化けしない形式（UTF-8 BOM付き）で書き出します。


■ 打刻忘れ通知

出勤から一定時間（初期値12時間）退勤の記録がないとき、
端末内の通知でお知らせします。
通知のオン/オフと時間は設定から変更できます。


■ プライバシー

・勤務記録は端末内にのみ保存されます
・開発者のサーバーへ送信しません
・アカウント登録は不要です
・氏名・メールアドレス・電話番号・位置情報を取得しません
・位置情報による自動出勤は実装していません

インターネットに接続していなくても、
出勤・退勤・休憩・集計・履歴・CSV書き出し・ウィジェットは
すべて通常どおり使えます。


■ 広告について

本アプリは広告を表示します。
ただし、出勤・退勤・休憩の操作を広告でさえぎることは一切ありません。
毎日使うアプリだからこそ、打刻の邪魔はしません。


WorkLog は「勤怠管理を全部できるアプリ」ではありません。
自分が何時間働いたかを記録する、いちばん簡単なアプリです。

主な機能（箇条書き用）
----------------------------------------------------------------
・出勤 / 休憩 / 退勤をワンタップで記録
・今日 / 今週 / 今月の勤務時間を自動集計
・1勤務につき複数回の休憩に対応
・日跨ぎ（夜勤）勤務に対応、出勤日へ計上
・履歴からの修正、打刻忘れ日の手動登録
・月単位の履歴表示と月間集計（勤務日数・総勤務時間・総休憩）
・CSV書き出し（Excelで開ける UTF-8 BOM付き）
・打刻忘れ通知（ローカル通知、時間変更可）
・ホーム画面ウィジェットから1タップ打刻
・週の開始曜日の設定（初期値：月曜日）
・ダークモード対応 / 日本語・英語対応
・オフラインで全機能利用可能

データセーフティ（Play Console 申告の下書き）
----------------------------------------------------------------
収集するデータ:
  - なし（勤務記録はすべて端末内に保存され、送信されません）

共有するデータ:
  - なし（開発者はデータを受け取りません）

第三者SDK:
  - Google Mobile Ads SDK (AdMob)
      広告の配信のため、広告 ID 等の広告関連データを Google が処理する
      場合があります。Play Console では「広告 ID」の項目を確認のうえ、
      AdMob の案内に従って申告してください。
  - Google User Messaging Platform (UMP)
      同意の取得が必要な地域で、広告に関する同意を取得します。

データの暗号化: 転送中のデータは広告SDKによる通信のみ（HTTPS）
データの削除要請: アプリのアンインストールで端末内データは削除されます

★ Play Console のデータセーフティ申告は、本番の AdMob 設定確定後に
  AdMob の最新ガイダンスと照合して最終確認してください。
